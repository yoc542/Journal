# Changelog

All notable changes to this project are documented in this file.

## [1.0.0] — 2026-09-02

First release.

### Added

- Daily journal with one entry per day.
- Today screen with writing status, word count, and quick access to journal features.
- Full-screen editor with automatic saving.
- Journal history with entry previews, editing, and deletion.
- First-run onboarding with optional Notion connection.
- Upload journal entries to Notion with sync progress.
- Import journal entries from Notion with conflict resolution.
- Settings for Notion connection, syncing, and reminders.
- Support for Android and Windows.
